# Trickster Quest Sender

แอป macOS (Swift/SwiftUI) ช่วยกดเควสส่งของแบบวนลูปใน Trickster ที่เล่นบนเบราว์เซอร์
โปรแกรมแค่ **คลิกเมาส์ กดคีย์บอร์ด และอ่านข้อความบนจอ** (OCR ของ macOS) ไม่ได้อ่านหรือแก้อะไรในตัวเกม
ผู้เล่นเดินไปหา NPC เอง

## ต้องมี
- macOS 14 (Sonoma) ขึ้นไป
- Xcode หรือ Command Line Tools (`xcode-select --install`)

## Build และเปิด
```bash
./build-app.sh
open build/TricksterQuestSender.app
```

## สิทธิ์ที่ต้องเปิด (System Settings → Privacy & Security)
- **Accessibility**: ใช้คลิก กดปุ่ม และปุ่มลัด F8/Esc
- **Screen Recording**: ใช้อ่านข้อความบนจอเพื่อเช็กว่ายังส่งเควสได้

เปิดสิทธิ์แล้วต้องปิดเปิดแอปใหม่ ถ้า build ใหม่แล้วใช้ไม่ได้ ให้ลบแอปออกจากรายการสิทธิ์แล้วเพิ่มใหม่

## ค่าเริ่มต้น: เควส Rookie G (Chaos Integer.62Byte)
1. หาป้ายชื่อ **Rookie G** หรือ **Part-Timer G** บนจอ (OCR) แล้วคลิกที่ตัว NPC เหนือป้ายชื่อ
2. กด 1 → ทำ [เควส]
3. กด 1 → รวบรวม Chaos Integer.62Byte
4. **เช็กข้อความ "ครบ 50"** บนจอ ถ้าไม่เจอภายใน 3 วินาที = ของไม่ครบ → หยุดทั้งหมดและส่งเสียงเตือน
5. กด 1 → ดูเหมือนจะขาดอะไรไปนะ...
6. กด 1 → รับบัคโค้ด [Holy]
7. กด 1 → เข้าใจแล้วจะช่วยหามาให้ (รับเควสซ้ำ)

## วิธีใช้
1. เดินไปยืนใกล้ NPC เอง ให้เห็นป้ายชื่อบนจอ
2. กด **F8** (หรือ fn+F8) หรือปุ่มเริ่มในแอป — ไม่ต้องชี้เมาส์ที่ NPC แล้ว
3. กด **Esc** เพื่อหยุดกลางคัน หรือขยับเมาส์เองก็หยุดทันที (ถ้าเปิดตัวเลือกไว้)

## ประเภทขั้นตอน
| ประเภท | ทำอะไร |
|---|---|
| หา NPC แล้วคลิก | อ่านป้ายชื่อ NPC บนจอ (ใส่ได้หลายชื่อ คั่นด้วย ,) แล้วคลิกเหนือป้ายชื่อตามระยะที่ตั้ง ถ้าไม่เจอภายในเวลาที่ตั้ง → หยุด |
| คลิกตรงเมาส์ตอนเริ่ม | คลิกจุดที่เมาส์ชี้อยู่ตอนกด F8 |
| คลิกตำแหน่งที่จับไว้ | คลิกพิกัดที่จับไว้ล่วงหน้า |
| กดปุ่มคีย์บอร์ด | กด 1–0, Enter, Space |
| เช็กข้อความบนจอ | อ่านจอซ้ำจนเจอคำนั้น ถ้าไม่เจอภายในเวลาที่ตั้ง → หยุดทั้งหมด |
| คลิกที่ข้อความ | หาคำบนจอแล้วคลิกตรงนั้น (ใช้แทนการกดเลข ถ้ากดเลขในเกมไม่ได้ผล) |

เคล็ดลับ: กด "ทดสอบอ่านข้อความบนจอ" ตอนที่บทสนทนาเปิดอยู่ เพื่อดูว่า OCR อ่านคำว่าอะไรได้
แล้วเลือกคำสั้นๆ ที่มีเฉพาะในกล่องบทสนทนา (อย่าเลือกคำที่อยู่ในแชตหรือหน้าต่างเควสด้วย)

ปุ่ม "ทดสอบหา NPC" จะหา NPC แล้วเลื่อนเมาส์ไปจุดที่จะคลิก (ไม่คลิกจริง) ถ้าจุดนั้นไม่ตรงตัว NPC
ให้ปรับ "จุดคลิกห่างจากชื่อ" (ค่าติดลบ = สูงขึ้น)

## โหมด "กดตัวเลือกจนบทสนทนาจบ" (ค่าเริ่มต้นตอนนี้)
1 รอบ = หา NPC แล้วคลิก → กด 1 ทุกครั้งที่บทสนทนา **เปลี่ยนหน้าจริง** → พอบทสนทนาปิด เริ่มรอบใหม่
- อ่านบรรทัดตัวเลือก `[1] ...` บนจอ แล้วกดเฉพาะตอนที่ข้อความในกล่องเปลี่ยนแล้ว เซิร์ฟเวอร์ช้าก็ไม่ข้ามหน้า
- หน้าค้างนานเกินที่ตั้ง (ค่าเริ่มต้น 2.5 วิ) = คิดว่าการกดหาย จะกดซ้ำให้
- คลิก NPC แล้วบทสนทนาไม่ขึ้น → ลองคลิกใหม่ ถ้าไม่ขึ้น 3 ครั้งติดจะหยุด
- "ต้องเจอข้อความนี้ระหว่างคุย": ถ้าบทสนทนาจบโดยไม่เคยเห็นคำนี้ = ส่งไม่ได้ → หยุด
- "หยุดทันทีถ้าเจอ": ใส่คำที่ขึ้นตอนของไม่ครบได้ ถ้ารู้ว่าเกมขึ้นคำว่าอะไร

## แท็บ (Preset) แบบเบราว์เซอร์
- แต่ละแท็บคือ preset หนึ่งชุด **แท็บที่เลือกอยู่คือชุดที่ใช้รัน** แก้ค่าแล้วบันทึกลงแท็บนั้นอัตโนมัติ
- คลิกแท็บ = สลับ · × = ปิดแท็บ · + = แท็บใหม่ · ดับเบิลคลิก = เปลี่ยนชื่อ · คลิกขวา = เปลี่ยนชื่อ / ทำสำเนา / ปิด
- คีย์ลัด: ⌘T แท็บใหม่ · ⌘⇧T เปิดแท็บที่ปิดล่าสุด · ⌘⇧] / ⌘⇧[ แท็บถัดไป/ก่อนหน้า · ⌘1–⌘9 ไปแท็บนั้น
- ระหว่างรันเปลี่ยนแท็บไม่ได้

## บันทึกการเล่น (สอนให้แอปจำ 1 รอบ)
1. ยืนใกล้ NPC → กด **● บันทึกการเล่น**
2. เล่นเอง 1 รอบในเกม: **คลิก NPC → กด 1 จนจบ → คลิกพื้นที่ว่างให้หน้าต่างเควสปิด** (อย่าเดินระหว่างบันทึก)
3. กด **F8** หรือ **■ หยุดบันทึก** → แอปสร้างแท็บ “บันทึก HH:MM” 3 ขั้นตอน:
   - **คลิก NPC** (อ่านป้ายชื่อใต้จุดที่คลิก)
   - **กด 1 จนจบบทสนทนา**: จำทุกหน้าที่เจอ + หน้าสุดท้าย
     กดเฉพาะตอนหน้าเปลี่ยนจริง (เซิร์ฟช้าก็ไม่ข้าม) · หน้าไม่เปลี่ยน 2.5 วิ = กดซ้ำ ·
     เจอหน้าที่ไม่เคยเห็น = ข้อความเปลี่ยน/ส่งไม่ได้ → หยุด · กดหน้าสุดท้ายแล้ว = จบรอบ
   - **คลิกพื้นที่ว่างเพื่อปิดเควส** (ตำแหน่งที่คุณคลิกตอนบันทึก)
4. ถ้าเปิด “บันทึกเสร็จแล้วรันต่อเลย” จะเริ่มรันใน 2 วินาที (Esc = ยกเลิก)

## แท็บที่ได้จากการบันทึก = preset ของรอบที่คุณเล่นเอง
- สร้าง: ปุ่ม **+** → **● บันทึกการเล่น** (หรือ ⌘⇧R) → เล่นในเกม 1 รอบ → F8
- บันทึกซ้ำ: ในแท็บนั้นกด **● บันทึกการเล่นใหม่** → ขั้นตอนเดิมถูกแทนที่ (เมื่อบันทึกใหม่สำเร็จเท่านั้น)
- บันทึก 1 ครั้ง = 1 แท็บ แท็บนั้นใช้สิ่งที่คุณเล่นไว้เสมอ: ชื่อ NPC, ลำดับหน้า, **ภาพของแต่ละหน้า**, หน้าสุดท้าย, จุดคลิกปิด
- ตอนรัน ขั้น "กดจนจบบทสนทนา" ตัดสินว่าเป็นหน้าไหนจาก **ภาพก่อน** (ไม่ขึ้นกับ OCR อ่านไทยถูกไหม) ข้อความเป็นตัวสำรอง
- หน้าใหม่ต้องเห็นตรงกัน 2 ครั้งติดก่อนกด · เจอหน้าที่ไม่ได้บันทึก = ข้อความเปลี่ยน → หยุด
- ถ้าหน้าตาเกมเปลี่ยนเล็กน้อยจนภาพไม่ตรงแต่ข้อความตรง จะใช้ภาพปัจจุบันแทนเฉพาะรอบรันนั้น สิ่งที่บันทึกในแท็บไม่ถูกแก้
